# El despertar de los mil colores: un viaje al corazón de Paloquemao

Experiencia web interactiva basada en la crónica periodística sobre la Plaza de Mercado de Paloquemao, ubicada en Bogotá, Colombia.

## Descripción

Proyecto académico que transforma una crónica escrita en una experiencia narrativa digital mediante fotografías, recursos multimedia, animaciones e interacciones.

El proyecto busca representar la biodiversidad, la cultura popular, la gastronomía y las prácticas de sostenibilidad presentes en la Plaza de Mercado de Paloquemao.
